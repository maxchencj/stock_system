# 模拟仓交易系统设计文档

**日期**：2026-05-30
**状态**：已确认，待实施

---

## 1. 背景与目标

### 现状问题
现有 `portfolio_tracker.py` 只记录买入价格，没有资金量、持仓手数、策略逻辑，盈亏只能算百分比，无法反映真实交易情况。

### 目标
基于自选股（`watchlist.json`），构建一套完整的模拟交易系统：
- 自动监控买卖点，触发时通知到专用 Telegram Bot（`@mcStockMessage_bot`）
- 支持传统技术指标（MACD、均线、RSI+KDJ）+ 缠论（顶底分型、笔、线段、中枢、背驰、三类买卖点）策略
- 具备历史回测能力（近1年，含手续费/滑点模拟），输出胜率供信号推送参考
- 账户支持动态仓位管理（总仓位 50%-80% 浮动，AI 根据市场状态建议加减仓比例）

## 2. 架构总览

### 模块位置
新建 `modules/sim_trading/`，与现有代码零耦合，仅共享：

## 4. 策略规则

### 4.1 传统技术指标

| 策略 | 买入条件 | 卖出条件 |
|------|---------|---------|
| MACD | DIF上穿DEA（金叉），MACD柱由负转正 | DIF下穿DEA（死叉），MACD柱由正转负 |
| 均线 | 价格上穿MA20，MA20>MA60多头排列 | 价格下穿MA20，或MA20下穿MA60 |
| RSI+KDJ | RSI<35超卖回升 + KDJ金叉 | RSI>70超买回落 + KDJ死叉 |

### 4.2 缠论策略

**基础结构识别（日K线）：**

1. **顶底分型**（`fractal.py`）：三根K线组合，处理包含关系后识别顶分型（中间K线最高）和底分型（中间K线最低）
2. **笔**（`bi.py`）：相邻顶底分型之间至少5根独立K线，构成一笔；笔的方向决定趋势
3. **线段**（`segment.py`）：至少3笔构成线段，方向为笔的主要方向
4. **中枢**（`zhongshu.py`）：至少3笔形成重叠区间 [ZL, ZH]，中枢是震荡区域
5. **背驰**（`beichi.py`）：当前笔对应的MACD柱面积 < 上一同向笔，判定背驰，趋势即将反转

**三类买卖点（`buy_sell.py`）：**

| 类型 | 买点条件 | 卖点条件 |
|------|---------|---------|
| 一买/一卖 | 下跌笔出现底分型背驰 | 上涨笔出现顶分型背驰 |
| 二买/二卖 | 一买后回调不破中枢底，再次上涨 | 一卖后反弹不破中枢顶，再次下跌 |
| 三买/三卖 | 价格突破中枢上沿ZH后回踩不破 | 价格跌破中枢下沿ZL后反弹不过 |

### 4.3 多策略共振（`combined.py`）

信号需满足以下任一组合才触发：

**买入共振组合：**
- 组合A：MACD金叉 + 缠论底分型确认
- 组合B：缠论一买/二买点 + MACD背驰
- 组合C：均线多头排列 + 缠论三买突破中枢

**卖出共振组合：**
- 组合A：MACD死叉 + 缠论顶分型确认
- 组合B：缠论一卖/二卖点 + MACD顶背驰
- 组合C：跌破关键均线 + 缠论三卖点

单一指标触发不推送，必须共振，减少误报。

## 5. 信号流转

```
自选股 watchlist.json
  │
  ▼ 每5分钟（盘中）
technical.py          ← 计算最新K线技术指标
  │ 有共振信号
  ▼
market_context.py     ← 采集：大盘涨跌、北向资金、外围市场
  │
  ▼
ai_advisor.py         ← Claude综合研判：
  │                      输入：技术信号 + 市场环境 + 历史胜率
  │                      输出：action(buy/sell/add/reduce/hold) + 建议仓位% + 理由
  ▼
risk_manager.py       ← 合规检查：
  │                      - 总仓位是否超80%
  │                      - 单股是否超20%
  │                      - 是否触发止损或回撤保护
  ▼ 通过检查
sim_notifier.py       ← 推送 @mcStockMessage_bot
  │
  ▼
trade_log.py          ← 记录信号到 sim_signals_log.json（用于胜率统计）
```

## 6. 风控规则

### 动态仓位上限

| 市场状态 | 总仓位上限 | 单次加仓上限 |
|---------|----------|------------|
| 强势（大盘涨+北向净流入+外围涨）| 80% | 15% |
| 中性 | 65% | 10% |
| 弱势（大盘跌+北向净流出）| 50% | 5% |
| 极端风险（大盘单日跌幅>2%）| 40% | 禁止加仓 |

### 硬性风控线（不可绕过）

- 单只股票最大仓位：20%
- 总仓位上限：80%
- 单笔浮亏超 -8%：自动触发卖出信号推送
- 组合最大回撤超 -15%：全面减仓至50%以下，推送风险警告

## 7. 回测设计

- **数据源**：Tushare 日K（前复权）
- **时间范围**：2025-01-01 至今
- **模拟细节**：手续费 0.3%（双向）+ 滑点 0.1%
- **基准对比**：沪深300

### 回测报告格式

```
📊 回测报告 | 洛阳钼业(603993)
时间范围：2025-01-01 ~ 2026-05-30

策略收益：+23.4%    基准(沪深300)：+8.1%    超额：+15.3%
最大回撤：-12.3%    夏普比率：1.42
总交易次数：18次    平均持仓：14天

信号胜率：67%（12/18次盈利）
最大单笔盈利：+18.5%   最大单笔亏损：-7.2%

表现最好：缠论二买+MACD背驰  胜率78%（7/9次）
表现最差：RSI超卖单独触发     胜率44%（4/9次）
```

回测结果缓存到 `data/backtest_results/{code}.json`，信号推送时直接读取胜率数据。

## 10. 实施优先级

**Phase 1（核心账户 + 基础策略）：**
- `account/` 三个文件
- `strategy/macd.py` + `strategy/ma.py` + `strategy/combined.py`
- `signal/signal_engine.py` + `signal/technical.py`
- `notify/sim_notifier.py`
- 定时任务接入

**Phase 2（AI 确认 + 市场环境）：**
- `signal/ai_advisor.py`
- `signal/market_context.py`
- `risk/` 两个文件

**Phase 3（缠论策略）：**
- `strategy/chan/` 六个文件（按依赖顺序：fractal → bi → segment → zhongshu → beichi → buy_sell）

**Phase 4（回测系统）：**
- `backtest/` 三个文件
- 胜率缓存与信号推送集成

**Phase 5（RSI+KDJ 策略）：**
- `strategy/rsi_kdj.py` 接入 combined.py
